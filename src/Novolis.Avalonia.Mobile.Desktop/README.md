# Novolis.Avalonia.Mobile.Desktop

Windows implementations of `Novolis.Avalonia.Mobile`: Credential Manager token store, `%LocalAppData%\Novolis\{product}\workspace`, system browser.

## Install

```bash
dotnet add package Novolis.Avalonia.Mobile.Desktop
```

## Quick start

```csharp
services.AddNovolisMobileDesktop("BooksMobile");
```
